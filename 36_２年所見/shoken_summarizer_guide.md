# 所見の文字数調整（100文字→80文字）失敗の理由と解決策ガイド

## 1. なぜ「100文字→80文字」の要約はAIで失敗しやすいのか？

学校の通知表や指導要録の「所見」において、100文字から80文字への圧縮は、一般的なAIにとって**最も失敗しやすいパターン**の一つです。

### 主な失敗の理由：
1. **「要約（Summarize）」と認識してしまう**
   - AIに「要約して」と頼むと、文章全体を要約しようとして40〜50文字程度まで縮めすぎてしまい、具体的なエピソードや頑張りが消えてしまいます。
   - 100文字から80文字への変更は「要約」ではなく**「字数調整・冗長表現の削ぎ落とし（推敲）」**です。
2. **AIは文字数ではなくトークン数でカウントしている**
   - LLM（GeminiやChatGPTなど）は「日本語の文字数」を正確にカウントするのが苦手です。「80文字で」と指定しても90文字になったり60文字になったりします。
3. **所見特有の文体・敬体の崩れ**
   - 語尾の「〜できました」「〜姿が見られました」といった通知表特有の丁寧な文体（です・ます調）が崩れてしまうことがあります。

---

## 2. 解決策：プロンプトの改善（ChatGPT / Gemini / Claude共通）

AIに指示を出す際は、「要約してください」ではなく、**「意味を変えずに冗長な言葉を削って字数を収めてください」**と指示するのが最も効果的です。

### 推薦プロンプト例：

```text
あなたは小学校の通知表「所見」の推敲のプロです。
以下の所見文（約100文字）を、内容・具体的成果・敬体（です・ます調）を維持したまま、言い回しをスリムにして【70文字以上80文字以内】に調整してください。

【制約条件】
・文字数は「絶対上限80文字、下限70文字」とします。
・「〜することができました」→「〜できました」のように冗長な言い回しを縮めてください。
・接続詞（また、さらに）や重複する修飾語を削ってください。
・児童の具体的な頑張りや成長のエピソードは削らないでください。
・出力は調整後の文のみを出力してください（説明や引用符は不要）。

【元の所見文】
（ここにA列の文章を貼り付け）
```

---

## 3. Googleスプレッドシートで自動処理する方法

### 方法A: Google Apps Script (GAS) + Gemini API を使う
`gas_script.js` をスプレッドシートの「拡張機能」>「Apps Script」に貼り付け、Gemini APIキーを設定することで、A列の文章を自動的に80文字以内に推敲してB列に出力できます。

### 方法B: Gemini Extensions / ChatGPT for Sheets を使う場合
スプレッドシートのアドオンや `=GEMINI()` 関数を使用している場合は、以下のように数式を記述します。

```excel
=GEMINI("以下の所見文の意味や敬体（〜できました）を変えずに冗長な表現を削り、75文字前後（絶対80文字以内）に推敲してください。文のみ出力してください。: " & A2)
```

## 4. 推敲のビフォー・アフター例（100文字 → 78文字）

### ビフォー（102文字）:
> 算数の学習では、かけ算九九の暗唱に毎日意欲的に取り組むことができました。休み時間にも友達と声を掛け合って練習し、全て合格することができました。今後もこの粘り強い努力を続けていってほしいと思います。

### アフター（78文字）:
> 算数ではかけ算九九の暗唱に毎日意欲的に取り組みました。休み時間も友達と練習し全段合格できました。今後もこの粘り強い努力を続けていくことを期待しています。
