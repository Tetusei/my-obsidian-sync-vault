# 三者面談 予約システム

Google スプレッドシート「三者面談」＋ Apps Script Web アプリ。
保護者はログイン不要・**メールアドレスを収集しない**。本人確認は
「クラス＋出席番号＋生徒氏名」の名簿照合と、予約時に発行する **4桁の予約コード**で行う。

- スクリプト: `1LHK4AkOudyYxBuaJmv7ynI8XFnDLvE8AujCwJVtnmd734bOSTVK_eFv2`

## 面談時間（既定値）

13:40 開始 / 面談 15 分 / 休憩 10 分 = 25 分サイクル × 6 枠

| | |
|---|---|
| 1 | 13:40 – 13:55 |
| 2 | 14:05 – 14:20 |
| 3 | 14:30 – 14:45 |
| 4 | 14:55 – 15:10 |
| 5 | 15:20 – 15:35 |
| 6 | 15:45 – 16:00 |

実施日は 2026/10/29(木)・10/30(金)・11/2(月)・11/4(水)・11/5(木)・11/6(金) の 6 日間
（11/3 は文化の日のため「実施する = FALSE」で入れてある）。

6 枠 × 6 日 × 4 クラス = **144 枠**（1 クラス 36 名まで）。
すべて「設定」「面談日」「クラス」シートで変更できる。

## 導入手順

1. スプレッドシートを開き、メニュー **三者面談 ▸ ① 初期セットアップ**
   （メニューが出ない場合は Apps Script エディタで `createOnOpenTrigger` を 1 度実行）
2. 「クラス」シートに 4 クラス分の担任名・担任メールを入力
3. 「生徒名簿」シートに クラス / 出席番号 / 生徒氏名 を貼り付け
4. 「設定」シートで、予約受付開始・締切・**管理パスコード**を入力
5. メニュー **② 枠を再生成**
6. Apps Script エディタ ▸ **デプロイ ▸ 新しいデプロイ ▸ ウェブアプリ**
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
7. メニュー **予約受付を開始する**（「設定」の `公開` が TRUE になる）
8. 発行された URL を保護者に配布

> Google Workspace for Education では、管理コンソールの設定によって
> 「全員（匿名）」でのウェブアプリ公開が禁止されている場合がある。
> その場合は管理者に許可してもらうか、「全員（Google アカウント必須）」に変更する
> （後者でもこのシステムはメールアドレスを保存しない）。

## 画面

| URL | 用途 |
|---|---|
| `<デプロイURL>` | 保護者用。予約 / 確認・変更・取消 |
| `<デプロイURL>?page=admin` | 担任用。管理パスコードで入る |

## シート

| シート | 内容 |
|---|---|
| `設定` | 開始時刻・枠長・休憩・枠数・受付期間・公開フラグ・管理パスコード |
| `面談日` | 実施日と、実施するかどうか |
| `クラス` | クラス名・担任名・担任メール |
| `生徒名簿` | クラス・出席番号・生徒氏名（**手入力**） |
| `枠マスタ` | システムの実体。1 行 = 1 枠。予約内容もここに入る |
| `全体ビュー` | 行 = 日付×時間、列 = クラス。**4 クラス横断で空きが分かる** |
| `予約表_1組` … | 担任配布・印刷用 |
| `予約ログ` | 予約・変更・取消の追記ログ |

`全体ビュー` と `予約表_*` は自動生成。担任が直接編集しても、次の更新で消える。
編集は `枠マスタ` かメニュー、または担任用 Web 管理画面から行う。

既存の `基礎データ` シートには一切触れていない。

## 担任の操作

**スプレッドシートのメニュー**
- 枠を再生成 / 全体ビュー・クラス別予約表を更新
- 未予約の生徒を表示
- 選択した枠をブロック（学級事務などで面談を入れない時間）／解除
- 選択した枠の予約を取り消す
- 予約受付を開始・停止 / 保護者用URLを表示

**Web 管理画面（`?page=admin`）**
- 日付を選んで 4 クラス分の予約状況を一覧
- セルをクリックで 空き⇔ブロック の切替、予約済なら取消
- 未予約の生徒一覧、印刷

## 設計上の注意

- **二重予約防止**: `LockService` で排他し、確定直前に枠の状態を読み直す。
  空き枠一覧は 15 秒キャッシュするが、確定はキャッシュを使わないため取り違えは起きない。
- **名簿を外に出さない**: 匿名アクセスの URL なので、生徒名のプルダウンは作らない。
  保護者が入力した氏名をサーバ側で照合するだけ。空き枠一覧にも予約者名は含めない。
- **総当たり対策**: 出席番号・予約コードの誤りが 15 分で 8 回続くと、その生徒について一時停止。
- 受付期間外は名簿照合そのものを行わない。
