三者面談 管理画面

⚠ 面談を入れない設定と、保護者の予約がぶつかっています
予約できずに困っている可能性のある家庭
セルを押すたびに 空き → ×（面談を入れない） → 生徒を登録 → 空き と一巡します。 2回目に押すと名簿から生徒を選ぶ小窓が出るので、電話で申し込まれた場合などに担任が代わりに登録できます （予約コードが発行されるので、保護者にお伝えください）。間違えて×にしたときは、その小窓の「空きに戻す」で戻せます。
「まとめて指定」をオンにすると、押してもすぐには変わりません。 選んだ枠が青くなって ✓ が付くだけです。同じセルをもう一度押すと選択が外れるので、 変わらないからと繰り返し押さないでください。
枠を選び終えてから 「× 面談を入れない」か「空きに戻す」を押した時点で、 選んだぶんがまとめて切り替わります。出張などで半日まるごと空けられないときに使ってください。 この画面での変更はすぐ保存され、保護者の予約画面にもすぐ反映されます。
ただしスプレッドシートの「全体ビュー」「予約表_〇組」は、負荷を抑えるため5分おきにまとめて書き換わります。 すぐ反映したいときは、上の 「シートの全体ビューを更新」 を押してください。 スプレッドシートを開いたままのタブは、そのあと再読み込み（F5）が必要です。
選択中 0 枠 選んだだけでは、まだ何も変わりません。 選んだ枠は青くなり ✓ が付きます。選び終えたら左のボタンを押すと反映されます。 日付・時間のセルを押すとその行の全クラス、クラス名を押すとその列の全時間をまとめて選べます。
緑=空き／灰=×（面談を入れない）／白=予約済／黄=予備。
黄色の「予備」は保護者に見えない枠です。押すと生徒を入れられます（出席番号か氏名。空欄にすると外れます）。スプレッドシートの「予約表_〇組」の（予備）の行からでも記入できます。
赤い ⚠ のセルは、面談を入れない設定にしたのに予約が残っている枠です。保護者への連絡が必要です。
ここで指定した内容は、スプレッドシートの「だめなコマ」シートにも反映されます。
